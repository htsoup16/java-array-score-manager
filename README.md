# Student Quiz Analytics Manager

A modular, Command-Line Interface (CLI) Java application designed to track, manage, and analyze student quiz scores. Built natively using foundational data structures and clean procedural logic without relying on external libraries or built-in utility methods.

## 🚀 Key Features
* **Dynamic Scope Definition:** Prompts users to define the dataset size dynamically (number of quizzes per student).
* **Comprehensive Analytics Engine:** Programmatically calculates overall class averages, individualized student performance metrics, and specific quiz-by-quiz statistics.
* **Input Validation:** Built-in error handling for non-existent record queries.
* **Interactive CLI Interface:** Implements a state-driven menu loop allowing users to continuously perform calculations until explicitly exiting.

## 🛠️ Technical Concepts Demonstrated
* **Multidimensional Arrays:** Used to model data matrices mapping relationships between students, scores, and quizzes.
* **Algorithmic Math Manipulation:** Average-calculation logic is completely hand-coded using primitive loops to showcase explicit control over numeric precision and traversal behavior.
* **Modular Software Design:** Segmented program functionality into dedicated methods to maintain single-responsibility principles.
* **User-Centric Indexing:** Abstracts zero-based indexing constructs behind a natural, one-based human UI interface.

## 📦 Requirements & Environment
* **Language:** Java (JDK 8 or higher)
* **IDE Used:** Eclipse IDE

## 📥 Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/htsoup16/java-array-score-manager
   ```
2. Open Eclipse IDE.
3. Select **File** > **Open Projects from File System...** and choose the cloned directory.
4. Run `MP1.java` as a Java Application.
